## Популярные стрижки

- **Классическая** — аккуратная стрижка с плавным переходом
- **Фейд** — короткие виски с плавным переходом к длинной верхней части
- **Андеркат** — выбритые виски и длинная верхняя часть
- **Помпадур** — классика с объёмом наверху

## Рекомендации

- Приходите с чистыми волосами
- Можно принести фото желаемой стрижки
- Уточните у мастера, как ухаживать за стрижкой
